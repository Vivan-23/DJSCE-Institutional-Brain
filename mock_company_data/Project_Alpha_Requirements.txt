# Project Alpha - Core Requirements Document

## Overview
Project Alpha is our new flagship SaaS product designed to streamline internal logistics for mid-sized e-commerce companies.

## Core Features
1. **User Authentication Module**: Must support SSO (Single Sign-On) and JWT based authorization.
2. **Dashboard UI**: Real-time tracking of logistics.
3. **Payment Gateway Integration**: Stripe integration for subscription billing.

## Dependencies
- The Dashboard UI (Frontend) absolutely depends on the User Authentication Module. No users can access the dashboard until SSO is completely deployed.
- Payment Gateway requires the User Database schema to be finalized.
