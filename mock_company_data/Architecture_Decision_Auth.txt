# Architecture Decision Record (ADR) 001: Authentication Provider

**Date**: April 10, 2026
**Author**: Alex Rivera
**Status**: Accepted

## Context
Project Alpha requires a robust authentication system capable of handling B2B Single Sign-On (SAML/OIDC) as well as standard JWT-based session management for internal users. 

## Decision
We will use Okta as our primary SSO provider and wrap it in a custom microservice for our frontend to consume. 

## Consequences
- **Positive**: Offloads security compliance (SOC2) for password storage to a trusted third party.
- **Negative**: Adds a hard dependency on an external network service for every user login. If Okta is down, our dashboard is inaccessible.
- **Negative**: The learning curve for integrating their new SDK is steep. The backend team will need dedicated time to implement the token exchange flow properly.
